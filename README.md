# CleanFoods

Blog sobre vida saudável e alimentação, desenvolvido em grupo no curso de Análise e Desenvolvimento de Sistemas (Senac São Paulo).

## O que é
Blog com conteúdo educativo sobre alimentação saudável que direciona o leitor para um site já existente de venda de marmitas.

## Tecnologias
Java, HTML5, CSS3 e Figma.

## Meu papel
Participei de todas as etapas do projeto: design das telas e desenvolvimento em Java.

## Código
O projeto está compactado em CleanFoods.zip.
